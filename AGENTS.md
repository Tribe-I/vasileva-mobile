# Работа с проектом

«От идеи к брифу» — мобильная версия учебного проекта для iPhone на React Native и Expo. Два экрана: бриф и сведения о приложении.

Установка: `npm ci`. Проверка TypeScript: `npx tsc --noEmit`. Запуск: `npx expo start`; открыть через Expo Go на телефоне.

Изменения делайте через отдельную ветку и pull request. Не добавляйте секреты, токены, персональные данные и адреса внутренних сервисов. Вымышленный пример должен быть явно обозначен, неподключённый поиск не выдавайте за работающий.
