# От идеи к брифу — мобильная версия

Приложение помогает продакту описать задачу, отредактировать и сохранить бриф. Это учебная мобильная версия проекта «От идеи к брифу» на React Native и Expo. Реальный AI-поиск не подключён; пример вымышленный.

## Обещания

1. На главном экране виден заголовок «От идеи к брифу».
2. Если идея пуста, кнопка исследования просит её описать и не отправляет запрос.
3. «Посмотреть пример» заполняет проблему и метрику и показывает отметку о вымышленном примере.
4. Проблему и метрику можно редактировать и сохранять полностью в `product-brief.txt`, в том числе после загрузки примера. На iPhone в системном меню нужно выбрать «Сохранить в Файлы».

## Запуск в Expo Go

Установите Node.js и выполните `npm ci`, затем `npx expo start`. Установите Expo Go на iPhone и отсканируйте камерой QR-код. Телефон и компьютер должны быть в одной сети.

Проверка типов: `npx tsc --noEmit`. Экран «О приложении» показывает `dev` локально либо короткий хеш коммита из `EXPO_PUBLIC_COMMIT` в сборке.

Не вводите секреты, персональные данные и информацию клиентов. Изменения предлагайте через ветку и pull request.
